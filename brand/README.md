# Brand assets

| File | What | Source | Size |
|---|---|---|---|
| `emhs-crest.png` | Ernest Manning High School crest | ernestmanning.cbe.ab.ca (site header, `/images/826-logo.svg`, actually a PNG) | 134x140 |
| `em-griffin-athletics.jpg` | EM letters + Griffin athletics mark | EMHS Griffins page on fan.hudl.com (organization avatar) | 225x225 |

Run `bash brand/get-logos.sh` to download both if they're missing.

Both are small. For sharper app icons, ask the school office or athletics department for higher-res originals (ideally SVG or 1024px PNG) and drop them in here with the same filenames.

These are the school's logos, used only in an internal tool for EMHS teachers.

Colours: navy `#0B1F3A`, gold `#C9A227`, white, plus accents sky `#4A90C2` and crimson `#B23A48`. Change them in `src/styles/theme.css`.
